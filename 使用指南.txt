  1. 这是什么？
══════════════════════════════════════════════════════════════

OpenClaw 是一个本地运行的 AI 助手平台。

简单说：
  - 你的电脑变成一个 AI 服务器（Gateway）
  - 浏览器打开就能跟 AI 聊天
  - 还能接入微信、Telegram、Discord、Slack、WhatsApp
  - 手机上也能随时随地用 AI
  - 数据全在自己电脑上，不经过第三方


══════════════════════════════════════════════════════════════
  2. 快速开始
══════════════════════════════════════════════════════════════

【第一步】打开控制面板
  按 Win+R，输入 cmd 回车，然后输入：

    openclaw dashboard

  浏览器会自动打开 http://localhost:18789

【第二步】开始聊天
  在页面底部的输入框输入消息，回车发送即可。

【第三步】（可选）接入聊天工具
  参见下方第 4 节。

  4. 接入聊天工具（微信、Telegram、Discord 等）
══════════════════════════════════════════════════════════════

  ⭐ 推荐: 微信（国人最方便！）

  ─── 微信接入步骤 ──────────────────────────────────────────

  【第一步】安装微信插件
  打开 cmd 或 PowerShell，运行：

    npx -y @tencent-weixin/openclaw-weixin-cli@latest install

  该命令会自动检测 OpenClaw 环境，完成插件安装并重启 Gateway。

  【第二步】扫码授权
  安装完成后，终端会自动弹出微信授权二维码。
  用微信扫码即可完成绑定。

  如果二维码没有显示，手动重新生成：

    openclaw channels login --channel openclaw-weixin

  【第三步】开始使用
  扫码成功后，微信里就能直接跟 AI 聊天了！

  ─── 微信接入注意事项 ──────────────────────────────────────

  1. 绑定后如果在聊天列表找不到机器人：
     → 在微信搜索栏搜索 "微信Claw" 或相关聊天记录内容即可找到
     → 目前已支持置顶功能

  2. 合规要求：
     → 插件目前处于 Public Beta（公测）阶段
     → 请遵守微信生态的内容合规规范

  3. 自动化任务建议：
     → 所有定时任务（Cron Tasks）建议在私密频道或文件传输助手中运行
     → 避免在群聊中触发，防止合规风险

  ──────────────────────────────────────────────────────────

  📱 Telegram（最简单，5分钟搞定）

  步骤：
  1. 在 Telegram 找 @BotFather，发送 /newbot
  2. 给 bot 起个名字，比如 "我的AI助手"
  3. 拿到 Bot Token（一串类似 123456:ABC-DEF... 的字符）
  4. 在电脑上运行：

       openclaw channel add telegram

  5. 按提示粘贴 Bot Token
  6. 在 Telegram 里给你的 bot 发消息就行了！

  ──────────────────────────────────────────────────────

  💬 Discord：

    openclaw channel add discord
    → 按提示创建 Discord Application 并填入 Token

  ──────────────────────────────────────────────────────

  💼 Slack：

    openclaw channel add slack
    → 按提示创建 Slack App 并配置

  ──────────────────────────────────────────────────────

  📱 WhatsApp：

    openclaw channel add whatsapp
    → 扫码连接 WhatsApp Web

  5. 多人共享一台 Gateway
══════════════════════════════════════════════════════════════

  如果办公室多个人想用同一台机器的 AI：

  1. 确保 Gateway 在运行：
       openclaw gateway status

  2. 同事在自己电脑浏览器访问：
       http://<这台电脑的IP>:18789

  3. 查看本机 IP：
       ipconfig
     找到 "IPv4 地址"，类似 192.168.1.100

  💡 技巧：设置一个固定 IP 避免每次都要查
     → 控制面板 → 网络 → 更改适配器设置
     → 右键网卡 → 属性 → IPv4 → 手动设置 IP

  6. 自定义 AI 模型
══════════════════════════════════════════════════════════════

  OpenClaw 支持多家 AI 模型：

  ┌──────────────┬───────────────────────┬─────────────────┐
  │ 提供商       │ 需要什么              │ 特点            │
  ├──────────────┼───────────────────────┼─────────────────┤
  │ Anthropic    │ API Key               │ Claude 系列     │
  │ OpenAI       │ API Key               │ GPT 系列        │
  │ Google       │ API Key               │ Gemini 系列     │
  │ OpenRouter   │ API Key               │ 聚合多家模型    │
  │ 本地模型     │ Ollama + 模型文件     │ 免费、离线      │
  └──────────────┴───────────────────────┴─────────────────┘

  切换模型：
    openclaw onboard
    → 重新选择提供商和模型

  用本地免费模型（Ollama）：
    1. 安装 Ollama: https://ollama.com/download
    2. 下载模型: ollama pull llama3
    3. OpenClaw 会自动发现本地模型


══════════════════════════════════════════════════════════════
  7. 开机自启设置
══════════════════════════════════════════════════════════════

  安装时已选择了 --install-daemon，通常会自动配置开机自启。

  如果没有自启，手动设置：
  1. 按 Win+R，输入 shell:startup
  2. 创建快捷方式：

      openclaw gateway start

  3. 把快捷方式放入启动文件夹

  8. 常见问题 FAQ
══════════════════════════════════════════════════════════════

  Q: 输入 openclaw 提示"不是内部或外部命令"？
  A: 重新打开一个 cmd 窗口，或手动刷新 PATH：
     set PATH=%PATH%;%LOCALAPPDATA%\Programs\openclaw

  Q: 浏览器打不开 localhost:18789？
  A: 检查 Gateway 是否运行：
     openclaw gateway status
     如果没运行：
     openclaw gateway start

  Q: AI 不回消息 / 报错？
  A: 检查 API Key 是否正确：
     openclaw onboard
     重新配置 API Key

  Q: 怎么换一个 AI 模型？
  A: openclaw onboard
     重新选择模型提供商

  Q: 怎么看 OpenClaw 在干什么？
  A: openclaw gateway logs

  Q: 微信扫码后找不到机器人？
  A: 在微信搜索栏搜索 "微信Claw" 或相关聊天记录
     目前已支持置顶功能

  Q: 微信插件安装失败？
  A: 确保 Node.js 已安装（node -v 检查）
     然后重新运行：
     npx -y @tencent-weixin/openclaw-weixin-cli@latest install

  Q: 想完全卸载？
  A: openclaw gateway stop
     npm uninstall -g openclaw
     删除配置目录: %USERPROFILE%\.openclaw


══════════════════════════════════════════════════════════════
  9. 网络配置（局域网访问）
══════════════════════════════════════════════════════════════

  让同局域网的其他电脑/手机访问：

  方法 A: 直接用 IP
    1. 查看本机 IP: ipconfig
    2. 其他设备访问: http://<IP>:18789

  方法 B: Windows 防火墙放行
    1. 控制面板 → Windows Defender 防火墙
    2. 高级设置 → 入站规则 → 新建规则
    3. 端口 → TCP → 18789 → 允许连接

  ⚠️ 注意：暴露到公网有安全风险，仅限内网使用！
